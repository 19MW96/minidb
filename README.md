# MiniDB

Eine kleine Datenbank in Java, die ich zusammen mit KI gebaut habe, um zu lernen, wie Datenbanken und Webserver funktionieren. Die KI hat mir beim Schreiben geholfen. Mein Ziel ist, jeden Teil zu verstehen und erklären zu können.

Ich mache eine Ausbildung zum Fachinformatiker für Anwendungsentwicklung und stehe beim Programmieren noch am Anfang.


## Was sie kann

- Kontakte speichern (Name und Nummer)
- Kontakte suchen
- Alle Kontakte anzeigen
- Kontakte löschen
- Speichert alles in einer Datei, damit nach einem Neustart nichts verloren geht
- Einfache Webseite zum Bedienen


## Technik

- Java 21
- Spring Boot (REST-API)
- Gson (JSON speichern und laden)
- JUnit (Tests)
- HTML und JavaScript (Webseite)



## Starten

1. Projekt in VS Code öffnen
2. Main.java starten
3. Im Browser öffnen: http://localhost:8080
